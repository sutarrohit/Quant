Extract Prisma into its own workspace package that owns the two non-backfillable Phase 1 tables,

Prisma-migrated tables via SQLAlchemy Core.

Purpose: `VALID-01` and `DATA-03` are the two histories the roadmap flags as impossible to
backfill. Every day the snapshot cron is not recording is a permanently missing row, and every
throwaway backtest that does not write a trial is a permanently dishonest denominator. Both need
the schema to exist before anything else can start recording.
Output: a migrated Postgres with `trials` and `symbol_listing_snapshot`, and two Python writers
that plan 01-05 (the tracer) and plan 01-06 (the cron) call.

| environment → connection string | `DATABASE_URL` carries a credential |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Tampering | `engine/persistence/*.py` SQL construction | high | mitigate | Every statement is a parameterized SQLAlchemy Core `insert()`/`select()` construct; the acceptance criteria explicitly forbid string-built SQL, and a grep for f-string SQL is part of the task's criteria |
| T-01-04 | Repudiation | `trials` row completeness | high | mitigate | `trial_recorder` writes a row on the exception path as well as the success path (D-15); the crashed-run test is a required passing test, so an experiment cannot vanish from the denominator |
| T-01-05 | Information Disclosure | `DATABASE_URL` in `prisma/.env` | medium | mitigate | Only `.env.example` is committed; `.env` is already covered by the repository `.gitignore`; the hosted credential is moved to a secrets manager in plan 01-06 (D-16) |
| T-01-06 | Denial of Service | local compose Postgres exposed on 5432 | low | accept | Development-only service bound to the local host with template credentials; no production data and no external exposure. The hosted cron database in plan 01-06 is separately credentialed |
| T-01-07 | Tampering | `symbol_listing_snapshot.raw_payload` | medium | mitigate | The raw response is stored compressed and never re-parsed for the extracted columns after write; extraction happens once, at capture, so a later parser change cannot rewrite recorded history |
